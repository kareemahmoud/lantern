# Lantern

A tiny command-line task tracker written in Python 3 (standard library only).

## Install and Usage

```bash
git clone https://github.com/<owner-username>/lantern.git
cd lantern
python3 lantern.py add "Buy milk"
python3 lantern.py list
```

## Commands

- `add` : add a new task
- `list` : show tasks (`--done`, `--sort`)
- `export --csv` : print the tasks as CSV

See the full guide in [docs/usage.md](docs/usage.md).
